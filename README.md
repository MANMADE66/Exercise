# 训练记录

给自己用的训练记录本：一张月历，点某一天就地展开，看那天的**计划**和**实际完成**——两块永远分开。

## 跑起来

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install flask flask-sqlalchemy
.\.venv\Scripts\python.exe run.py
```

浏览器打开 http://127.0.0.1:5000

## 怎么用

1. **循环模板**（月历右上角进去）：把八天循环填一次，选个起始日期点「铺到日历」，省掉每天手敲计划。已经排过的日期会跳过，不会覆盖你写好的东西；模板可以存多套，对应不同训练阶段。
2. **月历**：一天一格，点开就地展开。休息日、已记完的日子一眼能分辨。
3. **计划**：动作、重量、组数、次数；上移下移改顺序，删错了再添一条就行。
4. **练完**：在「实际完成」里点「按计划预填」，然后只改不一样的地方——重量、组数、次数、备注，改完自动保存。计划外的动作也能单独加。
5. **感受**：展开的底部有个输入框，随手写两句。第一版它只负责存下来。
6. **周体重**：月历最右边一列，每周填一次（短期体重波动基本都是水分，不值得按天记）。

## 数据与备份

- 所有数据都在 `data/app.db` 一个文件里（SQLite）。
- 备份 = 复制这个文件。想清空就把它删掉，下次启动会自动建一个空库。

## 这一版不做什么

- **不替你规划训练**：计划完全由你手动安排。模板只是复制骨架，不做任何决策，重量也不进模板。
- **没有对话**、没有智能建议、不碰计划以外的事。
- 不做手机版、不做多用户、不上云、不做每日身体数据。
