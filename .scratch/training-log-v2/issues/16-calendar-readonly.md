### 冒烟主线（HLD §12.0，票 17–20 共用验收依据）

两账号隔离观感贯穿全程：A 的月历/详情/模板里看不到 B 的任何东西。

1. **登录**：注册或登录 → 落本月月历。
2. **月历**：上/下月翻页并回来（标题与网格一致）；今天格加粗带「今天」；休息日显示「休息」；已记录的日期有小圆点；补齐格空白且点了没反应。
3. **展开**：点格子就地展开 → 再点收起 → 点另一天换天 → 切月自动收起；展开格高亮。
4. **计划列**：添加计划条目（重量试 `60`/`60kg`/`62,5`）→ 出现在末位 → 上移/下移调整 → 首条上移、末条下移静默成功 → 删除计划条目后已记录的实际条目仍在。
5. **实际列**：「按计划预填」连点两次不产生重复行；四字段失焦各自保存（改重量不冲掉备注；清空备注可保存）；计划外新增出现在末尾；删除实际行消失。
6. **感受**：写感受保存 → 详情不收起；清空再保存生效。
7. **模板**：新建（空名 → 「未命名循环」；天数 `abc` → 8、`20` → 12；只填前 3 天存下 8 天）→ 铺到日历（提示新建 N 跳过 M 并列出跳过日期；已排日期内容不变）→ 删除（确认一次后连同天/条目消失）。
8. **周体重**：非法输入（空/`abc`/负数）还原 + 行内提示；合法保存立即显示新值不刷新页面；保存后该周体脂率/备注不丢。
9. **会话**：登出回登录页；手工把 localStorage 的 token 改坏后操作 → 被送回登录页。
