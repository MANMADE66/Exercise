# 16: 月历只读网格 + 共享层预置

Type: task
Status: ready-for-agent
Blocked by: 无（可立即开工）

## What to build

登录后落在本月月历：表头「一 … 日」，整周网格按周一补齐，训练日显示当天标题、休息日固定显示「休息」、今天加粗并带「今天」标记、有实际条目的日期带「已记」小圆点；上/下月可翻。顶栏换成真实用户名 + 「月历 / 模板」导航（当前路由高亮）+ 登出。

同一票把后续四票都要用的共享层一次落定，避免每票改同一个文件：出海口模块补齐全部 14 个端点包装（入参与返回值全部取自生成类型）、纯函数模块（重量文本 / 剂量拼接 / 今天日期 / 月偏移 / 从 ISO 取月份）、方向 A 令牌与月历·表单·卡片样式整份迁入、`MonthGrid` 的展开行插槽（本轮无内容时不渲染）。

## Acceptance criteria

- [ ] 登录后落在本月；本月首尾按周补齐，补齐格空白、不可点、不画圆点
- [ ] 训练日格显示标题（无标题则不显示标签）；休息日固定显示「休息」；今天格加粗并带「今天」标记
- [ ] 「已记」圆点只由「该日存在实际条目」决定，与是否存在 PlanDay、是否有感受文本无关
- [ ] 上/下月按钮请求 `?month=YYYY-MM`；标题与网格以响应里生效的 `year`/`month` 为准
- [ ] 月历请求失败在页面顶部显示中文错误、不白屏，且能重试
- [ ] 顶栏：用户名、导航高亮、登出后清会话回登录页
- [ ] 出海口 14 个包装的入参/返回值全部取自生成物，无 `as` 断言、无手写后端形状
- [ ] 纯函数模块提供重量文本、剂量拼接、今天日期、月偏移；组件不各自重复实现
- [ ] 方向 A 令牌与月历/表单/卡片类迁入，类名与 v1 一致（不改名）
- [ ] HLD §12.0 的冒烟主线落成一份清单（后四票共用验收依据）
- [ ] `bash scripts/verify.sh` 全绿；`docs/openapi.json` / `api-types.ts` 零 diff

## Notes

- 本票是 prefactor + 第一个竖切合体：共享层单独成票在浏览器里看不出任何变化，故并进月历只读网格（spec「Further Notes」的切分建议据此调整）。
- 月历聚合的唯一持有者是月历视图；`MonthGrid` 只管表结构（表头、按周的行、格子状态类与展开行插槽），不持有日详情状态。展开行的 `colspan` 只在 `MonthGrid` 里写一次——后续票加列时只改这一个地方。
- 「已记录」与「当天有 PlanDay」是两条独立信息（`CONTEXT.md`），别合并成一条判断。视图把 `logged_dates` 转成 `Set` 再传，渲染循环里不做 `includes`。
- 契约不带 `today`，用前端本地日期算；只影响视觉标记，不影响请求。
- 样式整份迁入是机械操作（一个文件），不按页面拆票；骨架期新增的登录页与状态点样式追加在尾部。
- 本票不动后端，生成物若出现 diff 说明有人改了 Pydantic 模型——停下排查，不要 `git add` 蒙混。
